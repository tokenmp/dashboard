# 模型倍率与计费

## 计费公式

每次请求的实际扣费：

```
扣费额度 = 模型标准用量折算 × 该模型倍率（multiplier）
```

- **标准用量折算**：由上游返回的 token 用量（输入 / 输出等）按模型单价折算。
- **倍率（multiplier）**：每个模型一个系数，支持小数（如 `0.1` 表示一折）。倍率可能因供应商而不同，网关**按实际命中的最优倍率**计费。

## 哪里查倍率

- 公开站[模型页](https://tokenmp.cn/models)实时展示每个模型的当前倍率，与网关内部计费使用同一套数据。
- 控制台的请求明细中，每笔请求记录了**倍率本值落账**，可直接核对。

## 时间段倍率

部分模型配置了**时间窗倍率规则**：在指定时间段（如夜间低谷）自动应用不同倍率。规则生效时，请求明细中会体现该时间段内的实际倍率。

## 计费示例

假设某模型标准价为 1 额度 / 千 token，当前倍率 `0.1`：

| 请求 | token 用量 | 标准折算 | 实际扣费 |
| --- | --- | --- | --- |
| A | 1,000 | 1.0 | 1.0 × 0.1 = **0.1** |
| B | 3,500 | 3.5 | 3.5 × 0.1 = **0.35** |

若该模型在 00:00–06:00 配置了 `0.05` 低谷倍率，则该时段内请求按 0.05 计。

## 对账

控制台「账本 / 请求日志」提供逐笔明细：时间、模型、token 用量、倍率、扣费额度。如对某笔扣费有疑问，可凭请求 ID 联系我们核对。
