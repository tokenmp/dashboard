# 套餐类型与分组

TokenMP 套餐按**计费方式**分为三种类型，每种类型下再按**分组**细分。你在[套餐页](https://tokenmp.cn/plans)看到的左侧分段控件对应计费方式、右侧分类筛选对应分组。

## 按计费方式

| 类型 | 计费方式 | 限额计量 | 适合 |
| --- | --- | --- | --- |
| **Coding 套餐** | 按请求次数扣减 | 次数（各时间窗限额） | 编程 Agent / CLI 工具的重度使用 |
| **Token 套餐** | 按实际 token 用量扣减 | token 总量 | 对用量精细控制的应用接入 |
| **图片套餐** | 按图片生成次数 | 次数 | 图像生成场景 |

同一账号可以同时持有多种类型套餐，请求时按你的**计费偏好**选择（默认 Coding，可在控制台修改）。

## 按分组

以 Coding 套餐为例：

| 分组 | 含义 | 周期 |
| --- | --- | --- |
| **month（订阅制）** | 固定有效期，周期内限额刷新 | 默认 31 天一周期，到期后套餐失效 |
| **permanent（永久）** | 一次购买长期有效，无到期时间 | 无周期概念，只受总量限额约束 |

订阅制套餐支持多档位（如基础版 / 高级版 / 专业版），档位差异体现在各时间窗限额的大小。

## 模型白名单

部分 Coding 套餐带**指定模型范围**：

- 不限范围的套餐，所有模型都能用
- 限定了范围的套餐，只有范围内的模型请求会从它扣费；调用范围外的模型时自动改从你其他匹配的套餐扣

## 多套餐共存与扣费顺序

同时持有多个 Coding 套餐时，每次请求按**扣费策略**选择先扣哪个。默认策略（控制台可调）：

```
最近到期优先 → 剩余最少优先 → 限额小优先 → 先激活先用
```

- **最近到期优先**：快过期的先用完，永久套餐永远殿后
- 可选策略还包括：限额大 / 限额小、剩余最少 / 剩余最多、最晚到期、最新激活先用（同维度两向互斥）
- 无论策略如何排序，**模型白名单匹配的套餐永远最优先**
