# 联系我们

遇到问题或有合作意向，欢迎通过以下方式联系我们。

## 邮箱

[thesumwai@gmail.com](mailto:thesumwai@gmail.com)

- **技术支持 / 接入问题**：请附上请求 ID、时间与模型名，方便快速定位（可在控制台「请求日志」中查看）。
- **商务合作 / 定制套餐**：请简要说明需求场景与预期用量。

通常会在 1 个工作日内回复。
