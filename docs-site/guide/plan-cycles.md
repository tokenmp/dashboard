# 周期与限额

套餐额度会从几个时间维度同时约束你的用量，任何一个维度用完，请求都会被拒绝（错误码 `QUOTA_EXCEEDED`），直到那个维度恢复为止。

## 限额有哪些

| 限额 | 是什么 | 用完了怎么恢复 |
| --- | --- | --- |
| 滚动 5 小时 | 最近 5 小时内最多能用多少 | 不用操作，最早的用量滑出 5 小时窗口后自动恢复 |
| 每周 | 每个自然周最多能用多少 | 下周自动刷新 |
| 周期 | 一个计费周期内最多能用多少 | 周期结束时自动刷新 |
| 总量 | 套餐总共能用多少（永久套餐常见） | 不会恢复，用完需要再买 |
| Token 量 | Token 套餐专属：总共多少 token | 不会恢复，用完需要再买 |

你的套餐具体配了哪些限额、各是多少，以[套餐页](https://tokenmp.cn/plans)和控制台展示为准。多个限额同时生效时，先碰到哪个上限就先停。

## 周期怎么算

**订阅套餐（按月）**：从你激活的那天开始算一个周期（常见 31 天）。周期到了，周期额度和每周额度自动刷新，之前没用完的不累积。套餐到期后整体失效，需要续费。

**永久套餐**：没有周期的概念——买多少用多少，用完为止，不会过期。

## 超限时的表现

- 报错 `402 QUOTA_EXCEEDED`，提示当前套餐或余额不足（见[错误码表](/api/endpoints#错误码)）。
- 滚动 5 小时超限：等一等就自动恢复。
- 周期 / 每周超限：等刷新，或升级、兑换新套餐立即恢复。
- 总量 / Token 超限：需要再购买或兑换。

## 实用建议

- 跑批任务注意滚动 5 小时限额：短时间集中消耗容易触顶，可以拆开错峰跑。
- 同时有多个套餐时，快到期的会先扣，不用担心永久套餐被提前用掉。
- 给不同业务用独立的 API Key，用量和限额一目了然。
